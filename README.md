# mwp_sim: модель радиофотонного многодиапазонного преобразователя частоты

Модель во временной области для схемы статьи Scherbinin, Belov, «Multi-band Microwave Optics
Frequency Converter for Satellite Transmitter» (SYNCHROINFO 2020):

LD_i -> MZM1_i (гетеродин f_i, смещение в нуль) -> WDM MUX -> общий MZM2 (вход на f_c, смещение в
квадратуру) -> DEMUX -> PD_i -> BPF_i.

Аналитические амплитуды линий (формулы (13′) и (16) исправленного вывода к статье) реализованы в
`mwp_converter/analytic.py`. Модель численно с ними сходится (`tests/test_lines_13prime.py`, `tests/test_quadrature_16.py`).

## Установка и запуск

```
python3 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest tests -q
.venv/bin/python make_figures.py --fig all --quick --out figures/                  # быстрый прогон
.venv/bin/python make_figures.py --config configs/realistic.toml --fig 8 --out figures/
.venv/bin/python make_figures.py --fc 14 --flo 8 --direction upper --fig 5 --quick   # свои частоты
.venv/bin/streamlit run app.py                                                    # интерактивная страница
```

Для ноутбука `notebooks/demo.ipynb` ядро можно зарегистрировать (по желанию, меняет конфигурацию
Jupyter пользователя): `.venv/bin/python -m ipykernel install --user --name mwp_sim`.

Флаги `make_figures.py` перекрывают конфиг: `--fc --flo 5.5,9,17 --direction lower|upper --rs
--beta1 --beta-m`; `--fig all|1..8` (fig3 пишет ещё fig3b). Печатаются: `fs`, `band_report`,
время рисунков, таблица EVM/BER.

## Частоты

Нигде в коде частоты не зашиты: значения по умолчанию лежат в `configs/default.toml`. Задаются
TOML-конфигом, флагами CLI и полями ввода страницы.

| Сценарий | f_c, ГГц | f_i, ГГц | Выход, ГГц |
|---|---|---|---|
| Понижение | 30 | 5,5 / 9 / 17 | 19 / 12 / 4 |
| Повышение | 14 | 8 | 30 |

Частота f_1 = 5,5 ГГц выбрана потому, что при f_1 = 5 гармоника 4f_1 = 20 ГГц падает точно на
выход |2f_1 - f_c| = 20 ГГц (постоянный тон в полосе приёма, EVM около 22 %). `Plan.check()`
перечисляет паразитные линии 2k·f_i, f_c, 3f_c, |2k·f_i ± q·f_c|, попавшие ближе (1+α)·R_s к
выходу, и выдаёт запись уровня out (в `band_report`, stdout, на странице). Рис. 7(c) показывает
сравнение f_1 = 5 и 5,5 ГГц.

Инверсия спектра: линия |2f_i - f_c| несёт фазу -φ (нужно комплексное сопряжение) только при
2f_i > f_c. При 2f_i < f_c выход f_c - 2f_i несёт +φ (из (13′): -sin((2f_i-f_c)t-φ) =
sin((f_c-2f_i)t+φ)). Приёмник выбирает сопряжение через `Plan.line_info`.

Частота дискретизации подбирается автоматически: наименьшее чётное SpS ≥ 64, при котором
SpS·R_s ≥ 2,5·max(4f_i+3f_c, 3f_i+3f_c+(1+α)R_s). При SpS > 1024 выдаётся предупреждение.

## Конвенция β

В выводе фаза на плечо равна π·V/V_π, β = π·V_0/V_π. В OptiCommPy поле МЦМ равно
cos(π(u+V_b)/(2V_π)), поэтому драйв `u_0 = 2·β·V_π/π` (`model.beta_to_drive`). Смещения:
нуль — `Vb=+Vpi`, квадратура — `Vb=+Vpi/2` (знак «+» даёт |T_2|² = ½[1 - sin(2β_m sin θ_c)]).
Идеальный режим — `ER=300 дБ` (в OptiCommPy по умолчанию 60 дБ). Конечный ER задаётся встроенным
параметром `ER` функции `mzm`.

β_m определяется по RMS огибающей (mean|x|² = 1); для CW — по амплитуде тона. Пик RRC-QPSK
примерно в 1,6-1,8 раза выше RMS.

Конечный ER в модели OptiCommPy — дисбаланс амплитуд плеч при симметричном push-pull. Утечка
несущей оказывается в квадратуре с полем боковых, поэтому в фототоке линии f_i и f_i ± f_c не
появляются. Меняются только постоянная составляющая и уровень 2f_i (при любом дисбалансе плеч в интенсивности
остаются чётные гармоники f_i). Конечный ER нечётных линий не даёт; их даёт дрейф смещения
(`Impairments.bias_err`, доля V_π, актуально для космоса). При уходе δ = π·bias_err/2
отношение линий f_i±f_c к 2f_i±f_c равно |tan(π·bias_err)|·J1(2β₁)/J2(2β₁)
(`analytic.bias_error_ratio`, проверено тестом). Рис. 7(a1) показывает оптический спектр после MZM1
при разных ER (остаточная несущая), рис. 7(a2) — РЧ-спектр при дрейфе смещения 0/1/3/10 %.

## Шумы лазера

`RIN_var` из `basicLaserModel` не используется: шум в нём комплексный и стоит под корнем, а в коде
OptiCommPy есть пометка `todo`. `basicLaserModel` даёт только фазовый шум (ширина линии), а RIN
добавляется своим вещественным ΔP: E = sqrt(max(P+ΔP, 0))·exp(jφ), σ² = 10^(RIN/10)·P²·f_s/2
(односторонний RIN, белый в полосе Найквиста).

При прямом детектировании фазовый шум лазера компенсируется: оба МЦМ работают с одним и тем же
полем, и фототок зависит только от |E|².

## Полосы компонентов

`Response(kind, f3dB_GHz, order, csv_path)`: `ideal`, `rc`, `skin` (фаза нулевая), `brickwall`,
`supergauss` (только WDM, `f3dB_GHz` — полная ширина по -3 дБ), `csv` (`freq_GHz,S21_dB[,phase_deg]`).
Полосы стоят у РЧ-входов МЦМ1 и МЦМ2, у ФД и у каналов WDM. `band_report` ранжирует ослабление:
≤ 1 дБ ok, 1-3 дБ warn, ≥ 3 дБ out. Помеха соседнего WDM-канала добавляется некогерентно, биения
на шаге сетки не моделируются. `configs/default.toml` — идеал, `configs/realistic.toml` — полосы,
шумы, ER 30 дБ.

## Структура

`mwp_converter/`: `params.py` (план, конфиг), `response.py` (АЧХ, отчёт), `model.py` (лазер, МЦМ,
ФД, каналы), `signals.py` (PSK+RRC, приёмник, метрики), `analytic.py` ((13′), (16)), `spectra.py`,
`plots.py`. Тесты — `tests/`, ноутбук — `notebooks/demo.ipynb`, страница — `app.py`.

## Выходной BPF и форма импульса

- `[components.bpf]`: Баттерворт/Чебышёв I (`kind`), `order` (4), ширина `bw_factor·(1+α)·R_s`
  (по умолчанию 2) или `bw_GHz`, `center = "auto"` (следует за выходной линией) или число ГГц /
  список по каналам (фиксированный фильтр: при смене f_i линия уходит из полосы, `band_report`
  выдаёт out). Фильтрация цифровая и каузальная (`sosfilt`): учитываются групповая задержка и
  фазовые искажения. `bpf.suppression_table` — подавление паразитных линий в dBc к полезной.
- `[signal] pulse = "rrc" | "rect"`. `rect` — прямоугольные импульсы без формирующего фильтра
  (спектр sinc², полоса по первым нулям 2·R_s, `SimParams.alpha_eff = 1`); согласованный фильтр —
  интегрирование на символе.
- Страница: точки `m(t)` (вход МЦМ₂) и BPF₁–₃, вкладка Responses зависит от выбранной точки
  (`chain.response_view`), переключатель «Cumulative response» показывает сквозное ослабление
  цепочки полезной линии (`chain.chain_attenuation`; потери МЦМ действуют на индекс модуляции).
- Рисунок `fig9_bpf_output` (`--fig 9`): спектр до/после BPF, огибающая, созвездие; в stdout —
  таблица подавления.

## Noise sources (этап 1)

Все источники — поля `Impairments`, по умолчанию выключены; значения realistic — в
`configs/realistic.toml`.

| Источник | Модель |
|---|---|
| Вносимые потери (`[losses]`) | поле × sqrt(10^(-IL/10)) после МЦМ₁, MUX, МЦМ₂, DEMUX |
| Входной шум (`[input]`) | C/N на входе LNA в полосе R_s, NF каскада по Фриису F = F_LNA + (F_drv−1)/G_LNA; белый комплексный шум σ² = SpS/10^(C/N_eff/10) к огибающей (mean\|x\|² = 1), затем входной BPF (Баттерворт 4, `sosfiltfilt`); зашумлённая огибающая — `meta['x_in']`, эталон приёмника чистый |
| EDFA (`[edfa]`) | после МЦМ₂, до DEMUX: E = √G·E + n_∥, n_⊥ — вторая поляризация (в фототок по мощности), N_ASE = (GF−1)/2·hν, σ² = N_ASE·f_s; при идеальном WDM ASE ничем не фильтруется (warn в band check) |
| Усилитель после ФД (`[pd].amp_nf_dB`) | белый ток σ² = (F−1)·4kT·(f_s/2)/R_L |
| RIN, ширина линии, ER, дробовой и тепловой шум ФД | как раньше |

`budget.noise_budget` считает вклад каждого источника поверх базы («distortion floor»), строки
«all sources» и «sum of 1/SNR». `fig10_noise`: SNR на выходе против C/N на входе и столбики бюджета.
EVM realistic: ≈ 12,2 % с EDFA, ≈ 18,6 % без EDFA (основной вклад — входной шум C/N = 20 дБ,
без EDFA — ещё тепловой шум ФД при малой мощности).

### Noise sources (этап 2)

| Источник | Модель |
|---|---|
| Фазовый шум гетеродина (`[lo]`) | `noise.phase_noise`: S_φ = 2·10^(L(f)/10), L(f) — таблица (линейная в дБ по lg f, за краями — крайние значения); пресеты `synth_typical` и `dvbs2_mask` (маска ориентировочная, approx.); u₁ = u₀·sin(2πf_i t + φ_i), независимые реализации по каналам. Линия 2f_i получает 2φ, то есть +6 дБ — это следует из модели и проверяется тестом |
| Поблочная подстройка фазы (`[receiver].block_symbols`) | `metrics(..., block)`: глобальный g, затем поворот каждого блока на −arg Σ rx·s̄ (амплитуда глобальная); 256 символов; 0 — выключена |
| Драйверы (`[drivers]`) | `driver_poly`: y = u + a₂u² + a₃u³, среднее вычитается; A_IP3 = √(2R_L·10^((OIP3−30)/10)), a₃ = −4/(3A_IP3²), a₂ = 2·10^(HD2/20)/A_nom. Применяется к u₁ после фазового шума и к u₂ после входного шума, до АЧХ МЦМ. Шум драйвера гетеродина (≈ −178 дБн/Гц) не моделируется |
| Дрейф смещения МЦМ₁ (`[bias_drift]`) | `ou_process`: процесс Орнштейна–Уленбека (σ, τ), u₁ += b(t)·V_π. Внутри прогона (наносекунды) значение при τ = 1 с постоянно, поэтому нужен ансамбль (`fig11_bias_drift`, `drift_ens` — номер реализации) |

Ограничения: разрешение по отстройке фазового шума f_s/N (61 кГц для 2^14 символов, 488 кГц в
quick); при идеальном WDM ASE ничем не фильтруется; нелинейность усилителя после ФД, насыщение
EDFA и восстановление несущей/тактов не моделируются. `budget.noise_budget` дополнен строками
«LO phase noise (synth)», «LO phase noise (DVB-S2, ref.)» (справочно, в сумму не входит),
«drivers», «bias drift (1 draw)».
